# 🖥️ Графическая панель Tkinter и телеметрическая диагностика

Данный документ описывает структуру графического интерфейса пользователя, темную тему оформления и систему экспресс-диагностики **CARINA MOCK SERVER**.

## 1. Архитектура графического интерфейса

Интерфейс сервера построен на базе встроенной библиотеки **Tkinter**, с компоновкой на основе независимых карточек и темной цветовой палитрой (`ui/theme.py`).

### 1.1 Неблокирующий опрос состояния
Главное окно выполняет опрос данных каждые **250 миллисекунд** через `self.root.after(250, self._update_loop)`:
- Запрашивается неизменяемый `TelemetrySnapshot` из `TelemetryState`.
- Отрисовка происходит плавно, без блокировки потоков обработки сетевых пакетов gRPC.

---

## 2. Карточки интерфейса

1. **Заголовок (`ui/components/header.py`):** Фирменный логотип и индикатор активности сетевого соединения.
2. **Карточка подключения (`ui/components/connection_card.py`):** Сетевой адрес gRPC, текущее состояние (`IDLE`, `RUNNING`) и время с момента последнего пинга.
3. **Карточка сценария (`ui/components/scenario_card.py`):** Имя загруженной карты, контрольный хеш, число узлов и ребер, размер файла.
4. **Карточка потока (`ui/components/stream_card.py`):** Счетчик пакетов, номер последнего кадра и реальная частота в Гц (по окну из 20 отсчетов).
5. **Карточка диагностики (`ui/components/diagnostics_card.py`):** Баннер статуса данных (🟢 ДАННЫЕ АКТИВНЫ vs ⚠️ НУЛЕВЫЕ ДАННЫЕ), число активных дорог и таблица выборки полос.
6. **Карточка событий (`ui/components/events_card.py`):** Кольцевой буфер 15 последних системных сообщений.

---

## 3. Работа в фоновом режиме (Headless)

Для облачных серверов, Docker-контейнеров и конвейеров CI/CD без графического X-сервера:
```bash
python main.py --no-gui
# Либо через переменную окружения:
MOCK_SERVER_NO_GUI=1 python main.py
```
При невозможности запуска GUI из-за отсутствия дисплея сервер автоматически переходит в headless-режим.
